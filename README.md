# Testy Shop

Интернет-магазин, реализованный на Next.js с использованием публичного API [DummyJSON](https://dummyjson.com/).

---

## Стек технологий

- **Frontend:** Next.js (App Router) + React + TypeScript
- **Состояние:** Zustand
- **HTTP-запросы:** Axios
- **Стилизация:** SCSS-модули
- **Линтинг и форматирование:** ESLint, Prettier, Stylelint

---

## Функциональность

- Авторизация пользователей через JWT
- Отображение списка товаров
- Адаптивный дизайн (desktop / mobile)
- Валидация формы логина

---

## Установка

1. Клонируем репозиторий:

```bash
git clone https://github.com/denis290788/TestWork7433.git
cd test-work-7433
```

2. Устанавливаем зависимости:

```bash
npm install
```

3. Запуск в режиме разработки:

```bash
npm run dev
```

Открываем http://localhost:3000 для просмотра приложения.

## Линтинг и форматирование

Проверка кода на ошибки и соблюдение стиля (запускаются ESLint, Prettier и Stylelint)

```bash
npm run lint
```

Автоформатирование кода

```bash
npm run format
```
